## 1. Problem Summary

The repository root carries 26 tracked files plus several local artifact
directories that obscure the important entries. A structure review
(2026-09-16, `git grep` reference analysis over all tracked files) found:

- **Verified orphans** (zero inbound references): the legacy family-test
  runner chain (`scripts/run-family-tests.sh` + `.bat` +
  `scripts/setup-test-family.php` + its only consumer `tests/bootstrap.php`,
  superseded by `TEST_DB_PROFILE` + occ seeding per CS-PLAN-019),
  `scripts/run-docker-tests.sh` (CI drives `docker compose` directly), and
  `scripts/download-emojis.js` (one-off Fluent-emoji fetcher; no tracked
  emoji assets, no doc reference).
- **Stale tracked build artifact:** `css/chorestrike-main.css` (385-byte
  "Basic" stub) is overwritten by every webpack build
  (`MiniCssExtractPlugin` → `css/chorestrike-main.css`, `webpack.config.js:30`)
  while the sibling build output `/js/` is already gitignored.
- **Docker split across root and `docker/`:** `docker-compose.test.yml`
  sits at the root; everything else Docker lives in `docker/`.
- **Community/meta docs at root:** `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md`,
  `SECURITY.md`, `THIRD_PARTY.md` — GitHub/Forgejo auto-detect all of them
  in `docs/` as well; `THIRD_PARTY.md` is not linked from anywhere.
- **Test tooling writes clutter into the root:** the *visible* Playwright
  artifacts `test-results/`, `playwright-report/`, `.playwright/.auth/`
  (all ignored). The hidden tool dotfile caches (`.phpunit*.result.cache`,
  `.php-cs-fixer.cache`) stay at root by decision — see §2/WP4.
- **Duplication:** `phpunit.xml` exists only as the `composer test` config
  and mirrors the `phpunit.unit.xml` scope; CI always passes an explicit
  `--configuration`.
- **Encoding defects:** suspected mojibake (the E2 80-xx-as-cp1252
  em-dash signature) in `THIRD_PARTY.md` and a `jest.config.js` comment.
  *Implementation note (2026-09-16): both files are valid UTF-8 — the
  review saw display-level mojibake, not byte corruption (`docs:encoding`
  green on both; last content commits predate the CS-PLAN-052 signature
  detector). The literal sample once quoted here was itself real mojibake
  pasted into this plan and tripped the gate; it is now cited by escape
  only.* `docs:encoding` covers all git-tracked files since CS-PLAN-052.

## 2. Strategy

Four mechanical, independently verifiable moves in one pass (pre-release,
no compatibility constraints per project-rules §1):

1. Delete/archive the orphaned scripts and untrack the stale CSS artifact.
2. Relocate community/meta docs to `docs/` (root level — community-file
   auto-detection only checks root, `docs/`, `.github/`, not subfolders).
3. Move `docker-compose.test.yml` into `docker/` as
   `docker/compose.test.yml` and sweep every live reference (CI, engineering
   docs, skills, canonical rules). Historical records (`docs/plans/done/`,
   `docs/backlog/archive/`) stay verbatim.
4. Redirect the *visible* Playwright artifacts (test output, HTML report,
   auth storage states) into the already-ignored `build/` tree and retire
   the corresponding `.gitignore` root entries. The hidden tool caches
   (`.phpunit*.result.cache`, `.php-cs-fixer.cache`) deliberately stay at
   root: PHPUnit does not create parent directories for `cacheResultFile`,
   and the test container receives the app via COPY (no repo bind-mount),
   so a `build/` cache path would warn on fresh clones and in Docker
   (review finding RF-069-01).

Every step is followed by the reference sweep (`git grep` zero-residue
check) and the relevant gates; the Docker compose move is validated by a
full `up -d --build` + unit/integration run through the new path.

## 7. Risks & Mitigations

| Risk | Likelihood | Mitigation |
|------|-----------|------------|
| Compose resolves relative paths against the YAML's own directory — moved file silently builds/mounts the wrong context | High if unnoticed | Explicit WP3 sub-step re-basing every relative path inside the YAML; full `up -d --build` + integration run as gate |
| Missed live references to the old compose path break agent workflows/CI | Medium | Repo-wide `git grep` sweep is a dedicated work item + §4 residue check; `backlog:check`/`docs:encoding` rerun |
| GitHub/Forgejo community-file detection fails after the move | Low | Place files directly in `docs/` root (documented detection paths: root, `docs/`, `.github/`); no subfolder |
| CSS untracking surprises a contributor running the app without a build | Low | Already true for `/js/`; note in `docs/engineering/development.md` build prerequisite |
| `download-emojis.js` was a wanted one-off utility | Low | Preserved in `archive/2026-09/orphaned-scripts/` with README; recoverable |
| Editing canonical rules/skills drifts from upstream skill sources | Low | Skills are project-owned (`docs/standards/ai/skills/`); only path strings change |
