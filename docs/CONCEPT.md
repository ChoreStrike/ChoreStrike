# ChoreWars Concept Documentation

This document is the entry point for product concept documentation.

## Goal

Define ChoreWars as a cooperative, positive household task app in the Nextcloud ecosystem, with clear rules for planning, gamification, and multilingual support.

## Concept Document Structure

All concept content is now split into focused documents:

- [Product Vision](./concepts/PRODUCT_VISION.md)
- [Task Model and Nextcloud Sync](./concepts/TASK_MODEL_AND_SYNC.md)
- [Energy Model and Workload Balancing](./concepts/ENERGY_AND_BALANCING.md)
- [Gamification and Rewards](./concepts/GAMIFICATION_AND_REWARDS.md)
- [Internationalization and Content Policy](./concepts/I18N_AND_CONTENT_POLICY.md)

## Scope Rules

- **Security First:** Data and system security are paramount. The architecture and implementation must actively prevent accidental data exposure, unauthorized access, and adhere strictly to Nextcloud security standards.
- Keep concept text in English.
- Keep each concept document focused on one topic.
- Avoid third-party product names in user-facing concepts.
- Prefer neutral and family-friendly terminology.
