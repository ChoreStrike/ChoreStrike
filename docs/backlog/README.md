# Project Backlog

This directory contains the project backlog and task tracking for ChoreWars.

## Purpose

The backlog tracks:
- Planned features
- Known bugs
- Technical debt
- Future enhancements
- Research tasks

## Structure

Organize backlog items by phase or category:

```
backlog/
├── README.md (this file)
├── phase-1-core-tasks.md
├── phase-2-gamification.md
├── bugs.md
├── technical-debt.md
└── future-ideas.md
```

## Backlog Item Format

Each item should include:

```markdown
## [PRIORITY] Feature/Bug Title

**Status**: [Planned | In Progress | Blocked | Done]  
**Assignee**: [Name or unassigned]  
**Estimated Effort**: [S/M/L/XL]  
**Phase**: [1-8 or Future]

### Description
What needs to be done?

### Acceptance Criteria
- [ ] Criterion 1
- [ ] Criterion 2
- [ ] Criterion 3

### Dependencies
- Depends on: [Other tasks]
- Blocks: [Other tasks]

### Notes
Additional context, links, etc.
```

## Priority Levels

- **P0 (Critical)**: Blocking, must be done immediately
- **P1 (High)**: Important for current phase
- **P2 (Medium)**: Should have
- **P3 (Low)**: Nice to have
- **P4 (Future)**: Deferred to later phases
