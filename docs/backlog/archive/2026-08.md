## Items closed outside a plan

- **Route shadowing bug** (08-04, found by CS-023 E2E) — static single-segment
  routes registered after parameterized `{id}` routes were swallowed by
  Nextcloud's order-based router: `/room-tasks/overdue`, `/room-tasks/due-today`,
  `/room-tasks/due-within-days`, `/room-tasks/range`, `/room-tasks/overdue-claims`,
  `/room-tasks/filtered-daily`, `/tasks/daily`, `/tasks/categories`,
  `/tasks/templates`, `/tasks/search`, `/tasks/my-private`,
  `/rooms/needing-cleaning` all 500ed through the `{id}` handlers. Fixed by
  reordering `appinfo/routes.php`; guarded by
  `RouteMatrixTest::testParameterizedRoutesDoNotShadowLaterStaticRoutes`
  (RouteMatrixTest also wired into `phpunit.unit.xml` — it was never in a suite).
- **Notifier registration bug** (08-04, found by CS-023 E2E) — the legacy
  `<notifications>` info.xml tag is not wired on modern Nextcloud, so persisted
  ChoreStrike notifications never rendered in the bell. Fixed via
  `registerNotifierService()` in `Application::register()`.
- **E2E seed/auth fixture break** (08-04, found by CS-023 E2E) — CS-PLAN-019's
  `@PublicPage` removal left `database-fixtures.ts` + `auth.setup.ts` probing
  the test endpoints unauthenticated (401) and using GET on POST-only routes
  (405), so `seededData` was always null. Fixed with Basic-auth headers + POST.
- **Docker test image** (08-04) — `notifications` app added to
